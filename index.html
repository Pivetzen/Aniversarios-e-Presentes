Hospedagem Gratuita

Como publicar no GitHub Pages

Siga estes passos simples para colocar seu Web App no ar em minutos:

1

Criar um repositório no GitHub

Acesse o GitHub, crie um novo repositório público (ex: aniversarios-app).

2

Adicionar o arquivo index.html

Clique em Add file > Create new file no seu repositório. Nomeie o arquivo exatamente como index.html.

3

Colar o código

Copie todo o código deste arquivo, cole dentro do editor do GitHub e clique em Commit changes... no final da página.

4

Ativar o GitHub Pages

Vá na aba Settings > menu lateral esquerdo Pages. Em Build and deployment > Branch, selecione main (ou master) e clique em Save.

✨ Pronto!

Em cerca de 1 minuto o GitHub fornecerá o link público definitivo do seu Web App.
